# Online Quiz and Result System

A simple browser-based multiple-choice quiz built with HTML, CSS and JavaScript.

## Features
- Student name input
- Multiple-choice questions
- 60-second quiz timer
- Question progress indicator
- Automatic score calculation
- Result page
- Restart option
- Responsive layout

## Technologies
- HTML5
- CSS3
- JavaScript

## Run
Open `index.html` in a browser. No installation or server is required.
